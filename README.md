# 图片压缩工具

这是一个简单易用的在线图片压缩工具,可以帮助用户快速压缩图片文件的大小。

## 项目目标

为用户提供一个简单直观的在线图片压缩工具,帮助用户在保持图片质量的同时减小文件体积。

## 主要功能

- 支持上传 PNG、JPG 等格式的图片文件
- 可以预览上传的原图和压缩后的效果图
- 显示压缩前后的文件大小对比
- 支持自定义压缩比例
- 下载压缩后的图片

## 目标用户

- 需要压缩图片的普通用户
- 网站开发者
- 设计师

## 技术栈

- HTML5
- CSS3 
- 原生 JavaScript

## 文件结构

- index.html - 主页面
- style.css - 样式文件
- script.js - JavaScript 功能实现
- README.md - 项目说明文档

## 使用说明

1. 打开网站
2. 点击"选择图片"按钮上传图片
3. 调整压缩比例
4. 预览压缩效果
5. 点击"下载"按钮保存压缩后的图片
